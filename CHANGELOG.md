# Changelog

All notable changes to Neoroute will be documented in this file.

## 0.1.0

Initial MVP release.

- Self-healing, OpenAI-compatible gateway with fallback across providers
- Fail-closed capability-aware routing (vision/tools/json_mode/json_schema/audio)
- Structural response verification (`2xx` body checks, JSON parsing for `json_object`)
- Reliability evaluator with committed response corpus
- Windows PowerShell quick start in README, Examples and License sections added
